# Sources

Translations were read from native glyph records shown in quest_v8/NAMES_288.png and this folder's RECORDS_496.png and RECORDS_516.png. TRANSLATIONS.json contains all72 English records. ENGLISH_PROOF.png shows samples using the existing native font. No image-generated artwork or new textures are shipped.

Compact item-name localizations retain descriptions of actual effects. UTAGE remains the track title; Twilight translates Tasogare. Six red warnings retain their color controls and restrictions.
