Preserve spelling, brush letter shapes, purple QUICK and green BATTLES, ivory outline and black keyline, and wide horizontal proportions. Options prompt: Create a coordinated game menu lettering sprite sheet using ONLY the OPTIONS wordmark in the reference as style inspiration: dynamic readable English brush lettering, solid teal-to-deep-blue fill, ivory edge, clean black keyline. Exactly FIVE generously separated horizontal rows, exact text: GAME SETTINGS; CONTROLLER SETTINGS; SAVE; LOAD; SAVE DATA SYNC. Each row one line. All the same lettering height, longer rows can extend wider; no squashing. Smaller-menu readability: solid strokes, restrained texture, no tiny detached flecks, no shadows or panels. Actual transparent background preferred. If unavailable, use completely flat solid #FF8000 orange as an extraction background, never use orange inside the lettering. Complete words with generous clear margins and separation. No extra text.

Options extraction edit: Keep all five exact wordmarks unchanged: GAME SETTINGS, CONTROLLER SETTINGS, SAVE, LOAD, SAVE DATA SYNC. Preserve solid blue-teal strokes, white outlines and black keylines. Replace all background including counters and between letters with perfectly uniform flat #FF8000 orange. No gradients, clouds, glow, shadows, texture or noise in the background. Increase clear separation between rows if necessary so no strokes from neighboring rows overlap. No other changes.
