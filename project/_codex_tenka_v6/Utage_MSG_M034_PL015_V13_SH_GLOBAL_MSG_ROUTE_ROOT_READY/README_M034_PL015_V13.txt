Sengoku BASARA 3 Utage - m034/pl015 SH Global Message Route V13

Install: merge PS3_GAME into the extracted Utage root and overwrite.
Cold boot RPCS3 after installation.

This is the original V10 conversion artifact for the one mission file
whose live conversion failed because it was locked. It contains parallel
JPN and ENG message keys, both using the exact Samurai Heroes GSM/FIM
payloads. It has no mission-local TNF, CSA, or message atlas; formatting
resolves through the included active title_id.arc and basara.arc. The
companion rom/eng/msg/m034_pl015.arc is included byte-exact.

V11 is superseded: it dropped the parallel ENG message route.
V12 is superseded: it reintroduced a mission-local font path.

Runtime check: select Oda Nobunaga and Mount Osore. Confirm the opening
dialogue loads, is mixed-case/proportionally spaced, and the objective
text is English.
