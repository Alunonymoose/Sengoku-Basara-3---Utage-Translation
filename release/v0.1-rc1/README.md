# Sengoku BASARA 3 Utage — English Patch v0.1 Beta (RC1)

**First public fan-translation release candidate. Requires your own Japanese PS3 game.**

[Download the core patch from GitHub Releases](https://github.com/Alunonymoose/Sengoku-Basara-3---Utage-Translation/releases/tag/v0.1.0-rc1)

This release distributes a Windows installer and BSDIFF40 binary differences, not a retail ISO or original video/movie assets. The install engine validates SHA-256 of the original source.

## Verified acceptance

- Clean reconstruction passed: **5,052 installed files, 5,052 exact SHA-256 matches**.
- Includes **4,077 English ARC archives** and executable/resource patches.
- Japanese game files remain unchanged; mismatched Japanese source bytes are refused.
- Prior 15/15 static project QA passed; maintainer marked second boot, subtitles and cutscene transitions as passing spot tests.
- Full PS3 hardware certification and all campaign routes remain untested.

## Installation

1. Make a backup of a legitimately owned Japanese Sengoku BASARA 3 Utage PS3 game folder.
2. Download and extract the **entire** release ZIP.
3. Read the enclosed READ_ME_FIRST.txt.
4. Run Utage_English_v0_1_Beta_Installer.exe. It validates the original files before patching.
5. Keep your backup. If the installer rejects your Japanese game revision, do not bypass that protection.

## Known limitations

- **Original Japanese PAM movies are not changed by the core patch.** Video-specific repairs can follow separately.
- Some character/achievement titles and roulette/reward/story-heading artwork remain imperfect.
- Original signed trophy package stays Japanese; English trophy behavior is not fully validated.
- Real PS3/HEN, multiplayer, every route and cross-region Samurai Heroes save import are not certified.

See KNOWN_ISSUES.txt in the downloadable patch.
