# Contributing to BASARA Foundry

Contributions that improve the reusable reverse-engineering knowledge, tooling, tests, documentation or localisation methodology are welcome.

## Please do contribute

- format/structure discoveries backed by reproducible evidence;
- parsers, validators and safe writers;
- synthetic regression fixtures;
- corrections to existing technical canon;
- runtime/ownership experiments with clear expected outcomes;
- documentation that makes the work easier to reproduce;
- portability improvements for AI/human research workflows.

## Please do not upload

- retail ARC/TEX/XET/MSG/EBOOT/SELF/ELF files;
- extracted game trees or disc images;
- Samurai Heroes/Utage retail textures, audio or video;
- copyrighted game payloads from another source;
- credentials, private Drive material or personal information.

Use hashes, structural metadata, project-authored code, synthetic fixtures and concise observations instead.

## Evidence standard

A strong finding records:

`claim -> scope -> evidence -> experiment -> observation -> confidence -> implementation impact -> regression -> supersession`

Do not call correlation proof. Cross-game evidence from Samurai Heroes/Sumeragi/other MT Framework games should be labelled as reference evidence until Utage-specific evidence supports the claim.
